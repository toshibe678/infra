# このサービスについて
開発者が利用するMCPサーバーについて各開発環境のローカルリソースを利用するのではなく、統一的に提供して総リソース消費量を削減する目的でMCPサーバーを複数起動しそれを1つのインターフェースから提供することを目的としている
